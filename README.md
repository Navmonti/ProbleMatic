**How It Works**

Customers can create a new support ticket through the application. Once a ticket is submitted, the system routes it to the appropriate department. The ticket is then assigned to an available employee within that department.

**Development Plan**

**Phase 1** — Manual Assignment
Initially, ticket assignment will be handled manually. An authorized user can review tickets and assign them to the appropriate department and employee.

**Phase 2** — AI-Powered Assignment
In the next phase, we will introduce AI to automate the assignment process. The system will analyze each ticket, identify the appropriate department, and assign it to the most suitable available employee.
